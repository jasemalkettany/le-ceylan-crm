# Le Ceylan CRM

Operations CRM, admin and travel-agent portal for Le Ceylan.

- `src/` – source code (plain JavaScript)
- `docs/` – the built site, served by GitHub Pages
- `firestore.rules` – database security rules (paste into Firebase console → Firestore → Rules)

Backend: Firebase project `le-ceylan-crm` (Authentication + Firestore), owned by Le Ceylan.

## Build
    npm install
    npm run build
